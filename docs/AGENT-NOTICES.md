# DeepSeek Harness 与 Codex 消息提示

在「设置 → 消息提醒 → AI 助手」打开对应开关即可自动接入，不必打开文件夹或执行命令。旧版已开启的来源会在启动时自动补接。提醒总开关和来源开关都要开启；关闭只会静音，不反复改写客户端配置。

- **DeepSeek Harness**：完全退出客户端（包括系统托盘），再重新打开。设置显示「交互插件已连接」才表示当前运行的 DSH 已加载新版插件并连通岛仔，不必先发消息。只显示「已收到通知」或「等待交互插件连接」时，不能据此判断可在岛上审批。若提示未找到桌面配置，先启动一次客户端，再回岛仔点击「重试接入」。
- **Codex**：设置显示「已配置」后，在支持 hooks 的客户端查看并信任 Daozai hooks，再开新会话。岛仔不会代为信任或重启客户端。
- **确认操作能返回 DSH**：开启「岛上处理审批与提问」，把「自动交回」设为「不自动交回」。让 DSH 通过 `ask_user_question` 发一个单选题，等待超过 5 秒，再从岛仔提交；以原会话收到所选答案为准。普通聊天中用文字提问不会触发此工具。审批复验可选择「拒绝」，不需要实际放行操作。

## 审批与提问

打开「岛上处理审批与提问」（默认开启）后，请求以待处理卡排队，不受完成通知的停留时间影响。点「查看并审批」核对工具、目录和完整操作，选择「仅允许这一次」或「拒绝」。无法取得完整操作时不能在岛上允许。点「查看并回答」可回答 DeepSeek Harness 的单选、多选及自定义问题。关掉详情仅收起，点「回客户端」才交回原生界面。没有任何自动批准或永久授权。

详情卡右上角提供回到原客户端的入口：Codex 有线程标识时用官方深链精确打开原会话（「回到会话」）；DeepSeek Harness 把客户端窗口带到前台（「切换到客户端」），找不到窗口时回落到打开该会话的工作目录。跳转失败会在岛上提示具体原因，不会点了没反应。跳转只切换窗口，不改变请求状态。

岛仔只接管结构合法的请求：题干不超过 20000 字符、每题选项不超过 50 个、题目与选项不得重复或为空，题量与答案条数必须对应。超出范围或格式不合法的请求会立即交回客户端，不在岛上展示，避免异常数据拖垮界面。同一请求重复到达时只保留一条，不会叠加。

「自动交回」默认不自动交回，可选 5、10、15、30、60、120 秒；停留在卡片或查看详情时不会交回。请求仍受宿主实际生命周期限制，宿主撤销、退出或连接中断不等于允许。关闭交互或来源，会把尚未处理的请求交回。DeepSeek Harness 的「接收延后提问」默认关闭，只接收原客户端已进入 `continued` 的提问，不重写客户端的工作模式。Codex 通过 `PermissionRequest` 接收当前客户端实际发出的审批；本集成对 `request_user_input` 只做提示，作答仍在 Codex 内。

DSH 有些授权（如应用控制）是附带有效范围的特殊提问，不是一次性工具审批。岛仔可展示、拒绝或交回；要允许此类操作，必须回 DSH 核对授权范围。方案审阅同样由原客户端处理。

## 完成通知

可以关闭「任务完成提醒」，或选「轻提示 / 展开结果卡」，停留 2 至 15 秒，默认 5 秒。悬停暂停；有待处理卡时，先处理请求再显示完成通知。内容默认仅状态，也可选择本轮回复摘要（至多 1,200 字符）或本轮回复（至多 32,000 字符，可打开滚动阅读）。仅使用客户端事件提供的内容，没有正文则只显示状态；不读取历史补齐。「同时发送系统提醒」默认关闭，启用后遵循全局系统通知及声音设置，系统通知不显示回复正文。「本轮已结束」不代表任务成功。

## 配置与排查

岛仔将适配器保存在 `%APPDATA%\Daozai\agent-notices`（自定义数据目录时随之调整），在后台调用本机 Node.js；Windows 支持已安装的 Node.js 18+ 或 DeepSeek Harness 自带的兼容运行时。只处理开启的来源，不接管其他插件。配置有变化时在原文件旁保留 `.bak`；重复接入不重复注册。

Codex 默认目标为 `%CODEX_HOME%\hooks.json`，未设置时为 `~\.codex\hooks.json`。DeepSeek Harness 默认目标为 `%DSH_HOME%\profiles\desktop`，未设置时为 `~\.dsh\profiles\desktop`。不使用默认桌面 profile 时，可在接入文件夹运行 `node .\connect.mjs dsh install "D:\DSH\profiles\work"`，为该额外 profile 安装插件。

彻底移除时，先关闭岛仔对应开关，再在接入文件夹运行 `node .\connect.mjs codex remove` 或 `node .\connect.mjs dsh remove`，额外 profile 请传入其目录。重启对应客户端。

两个标识来自各自官方客户端。Windows 双向交互使用本机命名管道，不开放网络端口；本次请求、回答与回复内容仅在内存中处理，不进入岛仔通知历史或日志。岛仔不在线时交回客户端，不补发历史。旧版插件在 DeepSeek Harness 重启前只能发送固定状态提醒。
