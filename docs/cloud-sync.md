# WebDAV 云同步

设置 → 云同步，可在坚果云或自建 WebDAV 之间同步岛仔设置与邮箱账号。

## 第一台电脑

1. 在云盘中创建专用文件夹，例如 `Daozai`，并启用 WebDAV。
2. 填写该文件夹的完整 HTTP 或 HTTPS WebDAV 地址、用户名和应用密码。支持域名、IPv4 和 IPv6 地址。坚果云示例：`https://dav.jianguoyun.com/dav/Daozai/`；Tailscale 示例：`http://100.107.108.80:6086/Daozai/`（请先创建 `Daozai` 文件夹）。
3. 设置至少 12 个字符的同步密码。它与 WebDAV 应用密码分开，用于加密配置；所有电脑填写相同的同步密码。
4. 如需跨设备恢复邮箱授权码，请在两台电脑上勾选「同时备份和恢复邮箱授权码」（默认关闭）。然后点击「立即同步」。云端尚无文件时会创建 `daozai-sync-v1.json`。
5. 按需开启「每 5 分钟自动同步」，点击「保存连接」。自动同步仅在程序运行时执行。

## 其他电脑

填写相同的 WebDAV 文件夹、用户名、应用密码和同步密码，点击「用云端恢复本机」。通用设置恢复后生效。只有勾选授权码同步时，云端已有的授权码才写入本机 Windows 凭据管理器；不勾选时保留本机授权码。只有邮箱账号或授权码实际变化才重连；仅更改皮肤不会关闭正在阅读的邮件。

第一次连接已有配置时，程序不会自行判断应该用哪台设备覆盖另一台。选择「用本机覆盖云端」或「用云端恢复本机」完成首次对齐，之后即可自动同步。此功能不是邮箱注册或邮箱服务迁移。

## 范围

| 同步 | 本机保留 |
| --- | --- |
| 外观、小精灵、页面顺序与开关、时钟、歌词、专注饮水参数、收信间隔与验证码显示偏好 | 显示器绑定、本机应用路径、通知读取与邮件写操作权限、日程自动写入权限、未知或未来新增字段 |
| 邮箱地址、类型、开关、自定义 IMAP 配置；邮箱授权码需单独勾选 | WebDAV 地址与凭据、同步密码 |
| | 邮件正文与验证码、剪贴板、置物架、待办内容、饮水记录、日程连接与日程内容、已忽略会议的时间和标题、AI 登录与额度账号 |

本版覆盖设置与邮箱；不会打包整个数据目录。每台设备独立收信，云端不会收到邮件正文或验证码。

## 冲突与恢复

自动同步比较本机、云端与上次成功同步的配置摘要。本机单独修改时上传；云端单独修改时恢复；两端均有不同修改时暂停，并显示方向选择。恢复期间若本机又有修改，也会暂停，避免覆盖刚修改的内容。网络请求不阻塞界面。

恢复前会在岛仔数据目录的 `sync-backups` 子目录生成加密备份，默认目录为 `%APPDATA%\Daozai\sync-backups`，设置了 `DAOZAI_DATA_DIR` 时跟随该目录。备份使用当次同步密码加密，格式与云端文件一致。要恢复备份，先退出其他设备上的岛仔，保存当前云端文件副本，把所选备份上传为 WebDAV 文件夹下的 `daozai-sync-v1.json`，然后用对应密码点击「用云端恢复本机」。

WebDAV 写入使用 `If-None-Match: *` 创建文件、使用强 ETag 配合 `If-Match` 更新文件。请求期间其他设备写入会导致本次更新失败，重新同步后再决定方向。服务器若不返回强 ETag，程序拒绝覆盖已有文件；请使用支持这些条件请求的服务。文件夹需要事先创建。

本机未保存授权码是合法状态，停用邮箱也不会因此阻止恢复。凭据管理器发生访问错误时会停止操作，避免把读取失败误认为没有凭据。恢复失败会回滚配置文件和凭据，包括恢复为原来“没有授权码”的状态，并保留加密备份。

捕获快照、读取凭据、网络请求、加密备份和恢复均在后台线程执行。恢复前再次检查本机配置，避免覆盖期间的新修改。旧云端文件里的会议信息和设备权限会被忽略，后续上传使用明确的字段清单。

新版默认关闭授权码同步。首次使用新的同步范围时可能需要重新选择同步方向。取消勾选不会自动改写旧云端文件；如需从云端移除此前备份的授权码，取消勾选后使用「用本机覆盖云端」。各设备均应升级，避免旧版重新上传超出清单的字段。

## 密码与安全

- 云端文件整体使用 AES-256-GCM 加密，以 PBKDF2-HMAC-SHA256（600,000 次迭代）、随机盐生成密钥，每次加密使用新的随机 nonce。
- WebDAV 应用密码和同步密码保存在本机 Windows 凭据管理器；本机 `cloud-sync.json` 只保存连接地址、用户名、自动同步及授权码同步开关。更换服务器地址或用户名会清除表单中的旧密码，或仅加载新连接自己的凭据，不会将旧密码发送到新连接。
- 支持 HTTP 和 HTTPS，不跳转到其他地址，不把服务器错误正文或凭据写进状态提示。同步文件仍会加密；HTTP 的 WebDAV 登录凭据本身不受 TLS 保护，建议仅在可信内网或 Tailscale 中使用。
- 同步密码不正确或云端文件损坏时，程序不会上传覆盖，也不会修改本机。忘记同步密码后无法恢复旧文件；需更换专用文件夹，以本机现有配置重新初始化。
- 同步连接有未保存修改时自动同步暂停，保存后继续。关闭自动同步后请点击「保存连接」，以便下次启动仍保持关闭。

## 开发验证

沿用仓库 Windows MSVC 构建流程，无新增依赖，`Cargo.lock` 不变：

```powershell
cargo test --locked --lib cloud_sync -- --test-threads=1
cargo check --locked --all-targets --features record
```

单元测试包含加密往返、错误密码、篡改拒绝、冲突决策、连接地址与配置校验；本地模拟 WebDAV 测试覆盖首次创建、ETag 条件写入失败、云端恢复与错误密码禁止覆盖。正式接入自己的 WebDAV 前应在专用测试文件夹验证两台 Windows 电脑的邮箱凭据恢复。

也可以把修改推送到自己的 GitHub 仓库，在 Actions → Windows 检查 中运行工作流。完成测试与发布构建后，从该次运行的 Artifacts 下载 `daozai-windows-cloud-sync`，解压得到 `daozai.exe`。工作流支持手动运行，构建产物仅供下载，不会自动发布版本。
