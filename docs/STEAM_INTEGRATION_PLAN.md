# Steam 账号、游戏状态与成就提醒

状态：Steam 官网登录与 shapez 本地成就通知已由用户实测成功；独占全屏显示仍需实测。

## 用户场景

用户电脑安装并登录 Steam 后，能够在岛仔中连接自己的 Steam 账号并查看当前游戏状态。Steam 把新成就写入本地缓存或通过在线接口返回时，岛仔显示成就提醒。

## 第一版行为

- 在设置中提供 Steam 连接、状态说明和解除绑定入口。
- 浏览器跳转 Steam 官方登录页，以 OpenID 验证 SteamID64。登录失败、取消、超时均允许重试。
- 本机 Steam 账号检测仅作为便捷选择，不等同于登录验证；不读取 Steam 密码、登录令牌或 Cookie。
- 展示账号昵称、在线状态和当前游戏；无法读取时明确区分未连接、隐私限制、网络错误和离线。
- 游戏开始后建立成就基线，历史成就不弹出。后续检测到的新解锁进入岛仔通知队列。
- 支持指定游戏 AppID 或粘贴 Steam 商店链接，在游戏没有运行时持续跟踪。自动跟随模式继续只跟踪当前游戏。
- 提供本机通知预览和成就基线建立状态；已观察到的反解锁→再解锁，或新的解锁时间，会产生新的提醒。
- 通知展示游戏名、成就名称、图标和描述，支持设置显示时长；连续解锁按顺序展示，不覆盖当前提醒。
- 同账号、游戏、成就的解锁事件去重；重启、网络恢复、账号切换不得把历史成就重复提醒。
- 断开连接后停止轮询，清除本功能保存的凭据和账号缓存。

## 数据来源与边界

1. Steam OpenID 仅用于验证身份并取得 SteamID64，不授予访问私密游戏资料的权限，也不提供 Web API Key。
2. 官方 Web API `ISteamUser/GetPlayerSummaries/v2` 用于查询玩家概要；`ISteamUserStats/GetPlayerAchievements/v1` 查询指定玩家、指定游戏的成就，使用接口返回的本地化名称。Windows 通知读取 Steam 本地成就定义里的图标，并从 Steam 图片 CDN 按需下载缓存。游戏封面从 Steam 客户端图片缓存读取。
3. 上述玩家与成就接口需要 Web API Key。首版采用用户自备 Key、客户端直连 Steam 的方案（已与用户确认）；设置中提供获取 Key 的官方入口，密钥保存在 Windows 凭据管理器，不写入普通配置或日志。未来如需免填 Key，再另外设计服务端；不能把开发者密钥硬编码到客户端。
4. 存在跟踪游戏时约每 30 秒在线刷新玩家与成就，无跟踪目标时约每 60 秒刷新玩家。正常持续跟踪约 5,760 次调用／天，低于官方 100,000 次／天上限。玩家和成就读取失败时分别退避，最长 15 分钟。手动刷新会检查本地缓存，并请求在线状态。
5. 私密资料、离线游玩、游戏尚未同步成就、没有成就系统或接口不可用的游戏，可能无法获得完整状态。不能将这些情况显示为“没有成就”。
6. Windows 上独立检查 Steam 的本地成就缓存。每秒比较已绑定账号及跟踪游戏的两个缓存文件，修改时间或大小变化后再解析。本地和在线共用去重记录。Steam 决定何时写盘，客户端私有格式发生变化时可继续使用在线同步。
7. 新增 Steam 状态页，加入页面管理，可排序和隐藏。新增页默认开启，旧版页面顺序与隐藏状态会迁移保留。

## 接入现有代码的位置

- 新增独立 `src/steam.rs`：API 数据模型、轮询服务、缓存与新成就判定；后台线程处理网络请求，避免阻塞 UI。
- `src/main.rs`：衔接后台服务、把状态与事件推给应用。
- `src/app.rs`：保存 Steam 展示状态；复用现有应用事件处理模式。
- `src/extras.rs`：接入现有提醒队列；设置页提供连接和解除绑定。
- 凭据使用项目已有 Windows 凭据管理器方案；非敏感配置保存在岛仔数据目录。
- 保留原有默认全屏隐藏行为。为游戏中的成就提醒设计独立选项，并验证独占全屏下的显示限制。

## 验收

- 本机已登录 Steam 时，可完成明确的账号连接；用户取消或切换账号不会错误绑定。
- 当前游戏发生变化，岛仔能更新；网络失败不会冻结界面或把旧状态当作最新状态。
- 首次同步已有成就保持静默，新增解锁只提醒一次；多个成就、重启、重新绑定和网络恢复均覆盖测试。
- 明确显示 API Key 缺失、隐私限制与同步失败原因；解除绑定后不再获取数据。
- 合成数据覆盖解析、账号隔离、状态切换、成就基线、去重和退避；真实账号验收单独进行，不进入公共 CI。

## 使用首版

1. 打开「设置 → Steam」，通过「获取 API Key」进入 Steam 官方页面，在本机界面填写自己的 Key；不要把 Key 发到聊天、Issue 或提交记录。
2. Steam 客户端已登录时可点击「使用本机 Steam 账号」，也可以点击「在 Steam 官网登录」进行浏览器身份验证。
3. 进入游戏后，收起状态出现游戏图标，悬停可看游戏名；Steam 页面显示账号、游戏和成就进度。音乐页面独立显示音乐控制。
4. 游戏详情需要对 Web API 可见。第一次读取成就建立静默基线，后续新解锁进入现有通知队列。可单独开启「全屏游戏时允许提醒」；独占全屏与反作弊覆盖层限制尚未实测，不作可见性保证。
5. 无需重新输入 Key 即可刷新；更换账号／Key 需重新填写并连接。断开后停止访问并清除本功能凭据与去重缓存。

## 使用 Steam++ 验证成就通知

只开成就管理器而不运行游戏时，Steam 的玩家状态可能没有当前游戏。请在「设置 → Steam → 跟踪游戏」粘贴该游戏的 AppID 或 Steam 商店链接，点击「指定跟踪」。

1. 点击「预览成就通知」，先确认岛上能显示通知；此操作不访问 Steam，也不修改成就状态或成就基线。
2. 等待账号卡片显示所选游戏及「基线已建立」。首次同步历史成就保持静默。
3. 确认设置显示「正在监视本地缓存」后，在 Steam++ 解锁。Steam 写盘后岛仔通常在下一次检查时发现变化，在线接口也可以补报。
4. 重复测试同一成就时，先反解锁，等岛仔的成就计数下降，再重新解锁。两次写盘之间的变化只有在最终解锁时间更新时才能被区分。
5. 点击「恢复自动跟随」可回到只跟踪正在玩游戏的模式。指定跟踪时界面显示「成就跟踪」，不将未运行的游戏显示成「正在玩」。

本轮 Steam 专项回归 25 项通过，联网端点探测按规则跳过。旧去重缓存可迁移到带解锁时间的版本；相同状态不会重复提醒，已读取到的反解锁及更新的解锁时间会重新触发提醒。

## Steam 本机加速器兼容

Steam 登录核验和 Web API 请求在 Windows 上统一使用系统证书信任。本机加速器将 Steam 域名映射至回环地址并使用已安装的受信证书时，可沿用浏览器的信任链完成 HTTPS 连接。

本机已复现默认 Rust TLS 的 `UnknownIssuer`，并验证系统 TLS 能收到 Steam 官方 `check_authentication` 响应。修复后核心测试 14 项通过；无账号、无 API Key、无登录签名的真实端点探测单独通过，并确认无签名请求得到 `is_valid:false`。真实账号登录仍需重新发起浏览器流程验收。
