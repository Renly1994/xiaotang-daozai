# 多账号模式（账号岛）

管理多个 Claude、Codex 账号，并切换 Claude 桌面端的登录账号。默认关闭：不开启时，岛仔的 AI 额度页、读取的文件和后台任务都和原来一样。

在「设置 → AI 额度」打开「多账号模式」后，AI 额度页变成账号页。关闭后恢复原来的额度页，账号资料保留。

## 怎么用

| 操作 | 结果 |
|---|---|
| 点刘海上的圆环 | 打开这个账号的额度页 |
| 左右箭头 | 翻账号（翻页用滚轮或页码豆） |
| 双击账号名 | 小卡片：名称、邮箱、密码 |
| 双击圆环中间 | 完整详情；返回回到额度页 |
| 切换到此账号（点两次确认） | 关闭桌面端 → 同步会话列表 → 打开桌面端 → 从日志认出目标账号登录后才算切换成功 |
| 管理账号 | 正常 / 停用 / 封号、切换、无痕登录、移除 |
| 设置 | 添加账号、改资料、保存密码、对上桌面端账号 ID |

圆环的画法和原来的额度页一样：画的是剩余额度，外圈 5 小时，内圈本周。

## 刘海上显示什么

待机只显示正在使用的账号：圆环、眼睛、时间。

Claude 桌面端里有对话任务时，时间隐藏，改为显示任务名，眼睛变成表情：

| 状态 | 颜色 | 表情 |
|---|---|---|
| 进行中 | 红 | 愤怒地使劲干活 |
| 等你确认 | 黄 | 疑惑，旁边有问号 |
| 已结束 | 绿 | 高兴 |

- 任务名一条显示完再上下翻到下一条。只有一个任务时，长名字分几条显示；多个任务时每个占一条，太长就省略。
- 多个任务时，眼睛跟着翻到的任务变；`2/6` 这样的编号按任务出现的顺序排，状态变了也不变；右边是红、黄、绿各有几个。点文字打开任务列表，看完整任务名、项目和时长。
- 已结束的任务一直显示，直到你展开账号页再收起。
- 只看当前账号在桌面端里的对话，不包括终端里单独运行的 `claude` 和 Codex。

**“等你确认”是推测的。** 对话记录里没有批准提示，所以只有两种情况算：明确在提问或等确认计划；或者工具等了一段时间还没结果（读文件这类 20 秒，命令行和外部工具 60 秒）。一条真的要跑很久的命令可能被显示成黄灯。任务状态读的是桌面端的内部文件，它更新后可能需要跟着调整。

## 额度用完

当前账号的 5 小时或本周额度用完时，刘海只显示闪烁的红字，不再翻任务名，并短震一次（默认 3 秒）、发一条系统通知。还没换号就每隔一段时间再发一条（默认 5 分钟，默认不再震动）。这些都可以在设置里调，系统关了动画就不震动也不闪烁。换号或额度重置后不再提醒。

点红字打开快速换号页：列出其他 Claude 账号的剩余额度，点「切换」开始切换；还有任务没结束时要再点一次「仍然切换，中断任务」。等待登录时可以直接复制邮箱和密码。

这些都只是提醒和入口：不会自动换号，也不替你挑账号。请自行确认使用方式符合服务条款。

## 和原来的额度页有什么不同

| | 原来的额度页 | 多账号模式 |
|---|---|---|
| 额度来源 | 读取本机登录文件，调用服务商额度接口 | 官方 `claude -p /usage` 和 Codex 会话记录里的 `rate_limits` |
| 服务 | Codex、Claude、Kimi、Grok Bot、Gemini | Codex、Claude |
| 切换桌面端账号 | 无 | 有 |

多账号模式不读取、复制或上传任何令牌。切换只在用户点按钮后进行。

## 数据

数据在 `%USERPROFILE%\claude-hub`（可用环境变量 `CLAUDE_HUB_DIR` 改到别处），格式与独立桌面工具 claude-hub 相同，但不依赖它。如果这个目录里已有 `profiles.json`，首次启动会直接进入多账号模式。

切换前会把桌面端的会话列表整份备份到 `desktop-backups`，可以撤销。详见 [隐私与安全](PRIVACY.md)。

## 开发

代码在 `src/hub/` 和 `src/hub_ui.rs`。开发时把数据目录指到别处，避免碰到日常数据：

```powershell
$env:DAOZAI_DATA_DIR = Join-Path $env:TEMP 'daozai-development'
$env:CLAUDE_HUB_DIR = Join-Path $env:TEMP 'daozai-development-hub'
cargo run --locked --bin daozai
```

用合成数据导出各页面画面：设置 `DAOZAI_HUB_PREVIEW_DIR` 后运行 `cargo test --locked --lib --features record account_island_gallery -- --ignored`。

真实切换会关闭桌面端，自动测试不覆盖。
