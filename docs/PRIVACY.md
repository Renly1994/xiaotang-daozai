# 隐私与安全

## 本机数据

岛仔默认在 `%APPDATA%\Daozai` 保存用户设置、待办、本机日程及提醒设置、饮水记录、置物文件路径、连接元数据以及忽略的邮件日程标识。环境变量 `DAOZAI_DATA_DIR` 可指定另一目录。置物架保存原文件路径，不复制文件正文。本机日程不上传到工作日历。

邮箱和日历密码通过 Windows 凭据管理器保存；独立 Gemini 会话使用当前 Windows 用户的 DPAPI 加密。连接元数据中可能包含邮箱地址、账号名称和本机登录文件路径，因此整个数据目录都不适合公开上传。

程序读取收件箱内的邮件以展示正文、提取验证码与日历邀请。当前邮件记录保存在内存中；不要将运行中的内存转储公开分享。

## 网络访问

音乐兼容功能会只读访问汽水音乐、酷狗音乐的本机歌词缓存，以及网易云音乐的本机播放日志和播放队列；酷狗配置仅用于提取歌词目录。只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴，缺少系统封面时会从网易云图片服务获取专辑缩略图。日志正文、音频签名链接等内容不会保存或上传。网易云原生播放事件不依赖 SMTC 或固定内存地址；必要时仍可对已匹配的网易云、酷狗版本只读获取播放进度。不会修改播放器、读取音频或提取登录信息。启动或运行异常的诊断日志保存在数据目录的 `diagnostics/last-error.log`，不会自动上传。

启用对应功能后，程序会联系邮箱 IMAP 服务、工作日历 CalDAV / Exchange ActiveSync 服务、AI 服务额度接口以及歌词服务。连接方式和服务器见源码中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及对应 provider 模块。

点击「检查更新」时，程序会访问 GitHub 的公开发布接口，并在请求头中包含岛仔版本号，不发送本地设置、邮箱或日程数据。选择「下载并安装」会从 GitHub 下载公开安装包至 `%LOCALAPPDATA%\Daozai\Updates`，核对大小及 SHA-256 后替换程序并重启；「浏览器下载」通过默认浏览器打开发布页。

程序不使用统一的岛仔云端账号，也没有项目自建的邮件或日程上传后台。第三方服务自身的数据处理政策仍然适用。

## 登录凭据

Steam 功能仅在用户主动连接后获取玩家概要、当前游戏及跟踪游戏的成就。Windows 上会读取 Steam 的安装位置、运行游戏编号和当前客户端账号编号，并只读检查已绑定账号的成就缓存和跟踪游戏的成就定义。用户可指定游戏 AppID，在游戏未运行时继续跟踪。API Key 保存在 Windows 凭据管理器，按岛仔数据目录隔离。普通配置保存 SteamID、指定游戏 AppID 和提醒选项，岛仔的成就缓存保存账号／游戏编号、已解锁成就的内部名称及解锁时间，用于识别变化与去重。Steam 图片链接不包含登录凭据，已下载的成就图片缓存在岛仔数据目录中，游戏封面直接读取 Steam 客户端缓存。玩家昵称和游戏名称仅驻留内存。断开后停止轮询并删除岛仔的 Steam 凭据与成就状态缓存，清理失败会显示可重试的提示。

「使用本机 Steam 账号」仅读取当前 Windows 用户的 Steam 注册表账号编号，不读取 Steam 密码、登录令牌或 Cookie，也不表示完成了 Steam 官网身份验证。「在 Steam 官网登录」使用系统浏览器和本机临时回调端口，由 Steam OpenID 核验 SteamID；本机回调包含一次性随机值，验证完毕、取消或超时后关闭。API 请求直接发往 Steam 官方 HTTPS 接口，不经过岛仔服务器；API Key 不写入配置、缓存或错误提示。Steam 的数据隐私设置和网络／上传延迟会影响可读取的数据。

Windows 上的 Steam 请求使用系统 TLS 与系统证书信任，包括用户安装并信任的本机 Steam 加速器证书，同时校验证书和服务器主机名。连接错误只显示网络／TLS 类别或 HTTP 状态码，不显示 API Key、OpenID 签名或登录回调参数。

本机 AI 客户端的登录文件只读使用，不修改原客户端配置或替它刷新登录。独立连接的凭据由岛仔自己的安全存储管理。不要把 Cookie、授权码、登录 JSON、凭据文件、真实邮件或私人日程提交到 GitHub。
